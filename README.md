## 📂 Estrutura do Workspace

O repositório está dividido em trilhas de aprendizado distintas:

### 1. 🎓 [DIO - Introdução à Programação](./DIO/Intro%20a%20programação%20com%20Python/)
Focado nos fundamentos da linguagem e conceitos intermediários.
- **Básico:** Variáveis, loops (`for`/`while`) e condicionais.
- **POO:** Classes, métodos e herança (Ex: `aula7_televisao.py`).
- **Avançado:** Integração com APIs REST (ViaCEP/PokéAPI) e Web Scraping.

### 2. 📖 Book Python 3 - Learn Python the Hard Way
Exercícios focados em lógica rigorosa e manipulação de sistema.
- **I/O:** Manipulação de arquivos via linha de comando (`ex17.py`).
- **Sintaxe:** Formatação de strings e caracteres de escape.

### 3. 🛠️ Projetos e APIs
Desenvolvimento de aplicações e integrações com serviços externos.

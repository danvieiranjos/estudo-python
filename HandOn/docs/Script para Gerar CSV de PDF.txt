**Explicação:**

1. **Importar bibliotecas:** O script importa a biblioteca `tabula` para extrair tabelas do PDF e a biblioteca `pandas`
(opcional) para manipular as tabelas como DataFrames.
2. **Definir o caminho para o arquivo PDF:** Substitua `"seu_arquivo.pdf"` pelo caminho real para seu arquivo PDF.
3. **Extrair tabelas:** A função `tabula.read_pdf()` extrai todas as tabelas do PDF e armazena em uma lista chamada
`tables`.
4. **Criar lista para dados CSV:** (Opcional) Uma lista `csv_data` é criada para armazenar os dados das tabelas em formato
CSV.
5. **Iterar pelas tabelas:** O script itera por cada tabela na lista `tables`.
6. **Converter para DataFrame Pandas:** (Opcional) Cada tabela é convertida para um DataFrame Pandas usando
`pd.DataFrame(table)`.
7. **Salvar como CSV:** Cada tabela é salva como um arquivo CSV usando `df.to_csv()`, com o nome `"tabela_{index}.csv"`,
onde `index` é o índice da tabela na lista `tables`.
8. **Adicionar aos dados CSV (opcional):** (Opcional) Os dados de cada tabela podem ser adicionados à lista `csv_data`
usando `csv_data.append(df.values.tolist())`.
9. **Salvar todos os dados em um único arquivo CSV:** (Opcional) A lista `csv_data` pode ser salva como um único arquivo
CSV usando `with open("dados_gerados.csv", "w", newline="") as csvfile: ...`.

**Observações:**

* Instale a biblioteca `tabula` usando `pip install tabula-py`.
* O script assume que o PDF contém tabelas estruturadas.
* Se o PDF tiver várias páginas, use `pages="all"` para extrair todas as tabelas ou especifique um intervalo de páginas
(por exemplo, `pages="1-3"`).
* A conversão para DataFrames Pandas é opcional e pode ser útil para manipulação adicional dos dados antes de salvá-los
como CSV.

**Lembre-se:** Este script é apenas um ponto de partida. Pode ser necessário modificá-lo para atender às suas necessidades
específicas, especialmente se o formato do seu PDF for incomum.
